# AGENTS.md

Rules for AI agents working in this repository.

## Documents

Keep every document brief, yet comprehensive enough to convey the essential information and its intended purpose. Do not repeat content that already exists elsewhere in the repository; link to it instead.

## Relationship to the original repository

This repository was forked from https://github.com/rsjtdrjgfuzkfg/thunderbird-minimizeonclose, but is an independent project with no ties to it. Its releases, add-on listing, update channel, issues and support policies do not apply here.

The only exception: when the user asks, compare the original repository with this one, report changes this fork does not have, and explain how they could be applied here. Never apply them unless the user asks.

## Commit messages

Every time changes are made to the repository, provide a brief commit message for them. Base it only on the uncommitted changes: check `git status` and `git diff` first, never conversation history.

## Authorship

Never add co-authors or contributors to the repository. This includes `Co-Authored-By:` or similar trailers in commit messages, attribution lines in pull requests, and author or contributor entries in any file.

- [docs/SECURITY_ASSESSMENT.md](docs/SECURITY_ASSESSMENT.md): security and reliability review of the add-on.

Refer to them only when they provide context or instructions needed for the current task or question.
