# Minimize on Close add-on for Thunderbird

Minimizes Thunderbird's main window instead of closing it when you click the close button. Quit Thunderbird through the menu (**File → Quit**). Compose and message windows close as usual.

- **Compatibility:** Thunderbird 128 or newer.
- **Updates:** never installed from addons.thunderbird.net; new versions are installed manually.
